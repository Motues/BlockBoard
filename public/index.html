Edge mouse gestures block right-drag
A web page cannot turn off the mouse gestures built into Edge, so holding the right button to drag the board is taken over by the browser. Open the mouse gesture settings below (or paste the address into the address bar) and turn off "Enable mouse gestures"; newer builds also let you add this site to the gesture block list.
edge://settings/appearance/browserBehavior/mouseGestures
