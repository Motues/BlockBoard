# BlockBoard

一个实时在线的方块画板

[English](./README.md) | **中文**

![Index](./doc/images/index.png)

## 部署

1. 克隆仓库
    ```bash
    git clone https://github.com/Motues/BlockBoard.git
    ```
2. 安装依赖
    ```
    cd BlockBoard
    pnpm install
    ```
3. 启动服务
    ```
    pnpm build
    pnpm start
    ```
    然后打开 http://localhost:33333

## 配置

在 `game-config.json` 里配置服务端，参考 `game-config.json.example` 文件

| 字段 | 说明 |
| --- | --- |
| `rows` | 棋盘行数 |
| `cols` | 棋盘列数 |
| `cellSize` | 每个方块的像素尺寸 |
| `port` | 服务端监听的端口 |
| `devPassword` | 开发者工具的密码。留空则关闭开发者工具；环境变量 `DEV_PASSWORD` 的优先级高于这个字段 |
| `devSessionHours` | 开发者会话的有效时长（小时，默认 8） |

## 界面语言

界面支持中文和英文。第一次进入时按浏览器语言决定（`navigator.language`）：中文浏览器用中文，
其余一律英文。选择会记在浏览器里（`localStorage`，键 `blockboard-language`），之后随时可以在设置弹窗里改。

## 按钮

屏幕右下角、贴着最底部有三个圆形按钮：

| 按钮 | 图标 | 作用 |
| --- | --- | --- |
| **开发者工具** | 终端 | 登录 / 打开开发者工具（见下文） |
| **设置** | 齿轮 | 在屏幕正中间打开设置弹窗 |
| **菜单** | … | 打开选项面板：画笔颜色 / 重置视图 / 保存为图片 / 显示帮助 |

在移动端（触屏、没有悬停）会隐藏**开发者工具**按钮：开发者模式要用到左键和右键，只能在桌面端用。
**设置**则收进选项面板里（菜单按钮里的最后一项），所以在手机 / 平板上依然可以改语言和开发者密码。

## 画笔颜色

在棋盘上**右键短按**呼出画笔圆环：在约 220 ms 内松开、且光标移动不超过约 6 px，圆环就会在光标处弹出；
**按住不放**（或按下后直接拖动）则是平移棋盘，所以桌面端右键同时充当拖动把手。左键单击即可上色 / 擦除，
桌面端左键拖动不再平移视图。

> **Edge 用户注意**：Edge 自带的**鼠标手势**会占用右键拖动，而网页无法关闭它，长按右键拖动会变成浏览器手势、
> 棋盘就拖不动了。首次在桌面版 Edge 打开时，左下角会弹出一张提示卡片：卡片里的按钮会尝试打开鼠标手势设置页
> （`edge://settings/appearance/browserBehavior/mouseGestures`），同时把该地址复制到剪贴板（地址也直接印在卡片上），
> 浏览器不允许网页打开 `edge://` 时手动粘贴到地址栏即可。在那一页关掉**启用鼠标手势**就能恢复右键拖动；
> 较新版本也可以把本站加入鼠标手势的阻止列表。

圆环上是预设颜色；圆心的彩虹圆可以选**任意 24bit RGB 颜色**：点开后是带饱和度 / 明度区域、
色相滑条和十六进制输入框（`#rgb` / `#rrggbb`）的调色盘。选中的颜色立刻应用到画笔，并记在 `localStorage` 里。

调色盘里还有两个附加功能：

- **取色器** —— *完成* 左边的按钮进入取色模式。光标变成吸管，指向的方块会微微放大（不带平时的波浪动画），
  旁边跟一个小浮窗显示该方块的 `#rrggbb` 颜色。点一下方块就把它的颜色设为画笔色（能对上预设就用预设，
  否则是自定义的 24bit 颜色）并退出取色模式；`Esc` 取消。
- **最近使用** —— 调色盘顶部那一行色块保留最近 10 个画笔颜色（`localStorage`，键 `blockboard-recent-colors`），
  最新的在前并自动去重。纯黑会被跳过，因为黑色是擦除色。点色块即可重新选中。

## 设置

点齿轮按钮会在屏幕正中间打开一个小弹窗，里面有两个内容：

- **语言** —— 中文或英文，改完立刻生效。
- **开发者密码** —— 只保存在这台设备的浏览器里（`localStorage`，键 `blockboard-dev-password`）。
  它是一个便利项：点开发者工具按钮时会用这个密码自动登录，不用再手输一遍。留空保存等于清除。

这里的东西全部只存在浏览器里，不会发给服务端。**关闭** 会丢弃改动，**保存** 才会写入。

## 开发者工具

点底部按钮栏里的**开发者工具**按钮进入该模式：

- 如果这个浏览器里已经存了开发者密码，点一下就直接用它登录，不弹任何框。
- 如果还没存过密码，则弹出密码框。登录成功后会把密码记在这个浏览器里。
- 如果存着的密码被服务端拒绝（返回 `401`），会忘掉这个密码，并重新弹出密码框让你输入。
- 如果服务端没有启用开发者工具（既没有 `DEV_PASSWORD` 也没有 `devPassword`），点击只会提示一下；
  失败次数过多则提示已被暂时锁定。

登录会把密码换成一个随机的 32 字节 token：它存在服务端内存里 `devSessionHours`（默认 8 小时），
同时存在浏览器的 `localStorage`（`blockboard-dev-token`）里，所以刷新页面会话还在。
退出登录会立刻在服务端作废它，重启服务端则所有 token 全部失效。同一个 IP 连续失败 5 次会被锁定 5 分钟。

模式开启期间屏幕顶部常驻一条提示条，上面有 **退出** 按钮。

- **左键**：拖拽框选一个矩形 —— 按下后直接移动就开始框选，按住原地不动约 260 ms 也会进入框选，
  两种方式矩形都会跟着光标走。没有拖动的单击（移动不超过 6 px）则是把操作目标切换成该方块所在的闭合区域。
  这个模式下不能正常上色。
- **右键**：打开当前目标的操作菜单：填成画笔色、重置为黑、从调色盘里选一个自定义颜色、导出（PNG + JSON）。
  有矩形选区时菜单里还会多一项「取消选区」。菜单里不再列预设调色板的颜色。
- **闭合区域填充**在浏览器里计算：从点击的方块出发做四连通 flood fill，只要碰到棋盘边缘就不算闭合，
  此时会拒绝操作并提示「区域没有闭合」，而不是把整块棋盘刷掉。

这些操作最终走 `POST /api/dev/paint`。
